\# Activity Logger — Setup Guide



\## 1. Purpose



This document explains how to set up, run, test, and verify the Activity Logger application in a local development environment.



The Activity Logger consists of two applications:



\- \*\*Backend\*\* — Node.js and Express REST API

\- \*\*Frontend\*\* — React application powered by Vite



The backend stores activities using SQLite.



\---



\## 2. Prerequisites



The following software is required:



| Software | Purpose |

|---|---|

| Node.js 18+ | Runtime for the backend and frontend tooling |

| npm | Dependency management |

| Git | Version control |

node --version
